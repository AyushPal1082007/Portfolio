## ⚙️ Running Locally

### Option 1 — Direct Open
Just double click `index.html` — opens in browser instantly.

### Option 2 — VS Code Live Server (Recommended)
1. Install **Live Server** extension in VS Code
2. Right click `index.html`
3. Click **Open with Live Server**
4. Opens at `http://127.0.0.1:5500`

### Option 3 — Python Server
```bash
python -m http.server 3000
```
Then open `http://localhost:3000`

## 🚢 Deployment

This portfolio is deployed on **GitHub Pages**.

### First Time Setup
1. Push your code to GitHub
2. Go to your repo on GitHub
3. Click **Settings**
4. Click **Pages** in the left sidebar
5. Under **Source** select **Deploy from a branch**
6. Select **main** branch and **/ (root)** folder
7. Click **Save**
8. Your site will be live at:
🌐 **Live Site:** [ayushpal1082007.github.io/Portfolio](https://ayushpal1082007.github.io/Portfolio)
